# Operations API Practice

Сквозной кейс: «Лента истории операций».

## Подготовка
1. Установить VS Code + плагины (OpenAPI Editor, YAML).
2. Установить Node.js и Java.
3. Установить глобально инструменты:
   npm install -g @stoplight/spectral-cli
   npm install -g @apidevtools/swagger-cli
   npm install -g @openapitools/openapi-generator-cli

## Проверка
Откройте `test-openapi.yaml` и убедитесь, что плагин подсвечивает синтаксис и справа есть иконка Swagger UI.
